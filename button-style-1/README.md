# Yepi Kitten Button — Style 1

Neon liquid gradient button. Part of the [Yepi Kitten Button](../README.md) project — see the root README for how the kitten animation works and what's customizable.

## Development

```sh
npm install
npm run dev
```

```sh
npm run build     # production build
npm run preview   # serve the production build locally
npm run lint       # eslint
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
